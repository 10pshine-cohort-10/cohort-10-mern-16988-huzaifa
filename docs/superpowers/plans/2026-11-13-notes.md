# Shine Notes Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Deliver the cohort Notes App with tests and a reviewable pull request.

**Architecture:** React calls same-origin Express endpoints under /api. Controllers validate requests, services enforce authentication and ownership, and repositories execute PostgreSQL queries.

**Tech Stack:** TypeScript, React, Express, PostgreSQL, Tiptap, Pino, Mocha/Chai, Jest, SonarQube.

**Spec:** docs/superpowers/specs/2026-11-13-notes-design.md

## Global constraints

Preserve upstream CodeRabbit configuration. Keep secrets in environment variables. No pushing to upstream branches or merging. No external account setup.

## Review focus

- A second user must never retrieve, update, or delete another user's notes.
- Invalid and expired sessions must fail closed, including after logout.
- Rich text must not execute scripts or contain unsafe URL schemes.
- Failed saves and canceled edits must preserve the saved note.
- Changed origin, port, database URL, and production cookie settings must reach their consumers.

### Task 1: API and persistence

**Files:** server/src/{app,config,db,errors,index,logger,migrate,repository,services}.ts, server/src/schema.sql, server/test/api.test.ts, server/test/services.test.ts

**Interfaces:** createApp(repository: Repository, config: Config, logger: Logger) produces an Express app. Repository stores users, hashed sessions, and owner-scoped notes. /api/auth/{register,login,logout,me} exposes sessions; /api/notes and /api/notes/:id expose CRUD.

- [ ] Write Mocha/Chai tests for auth, CRUD, ownership, sanitization, errors, and session revocation; run and inspect failure.
- [ ] Implement schema, repository, service validation, routes, Pino, and global exception handling.
- [ ] Run API tests and TypeScript checks; commit the passing API.

### Task 2: React interface

**Files:** client/src/{App,AuthForm,Dashboard,NoteEditor,api,types}.tsx or .ts, client/src/styles.css, client/src/**tests**/*.test.tsx

**Interfaces:** User contains id/name/email. Note contains id/title/content/createdAt/updatedAt. API requests include cookies and handle JSON errors.
